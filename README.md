# ✈️ TravelMatrix AI – Multi-Agent Travel Planner

An AI-powered travel planning application that generates personalized travel itineraries using a multi-agent architecture. Built with LangGraph, FastAPI, MCP (Model Context Protocol), and modern web technologies.

## 🚀 Live Demo

🌐 https://travelmatrix-ai-a-multi-agent-travel.onrender.com

## ✨ Features

- 🤖 Multi-Agent AI workflow with LangGraph
- 🔗 MCP Client & Server integration
- ✈️ Personalized travel itinerary generation
- 🏨 Hotel recommendations
- 🛫 Flight search integration
- 🌍 Destination research
- 💬 LLM-powered travel assistant
- 🌐 Responsive HTML, CSS & JavaScript frontend
- ⚡ FastAPI backend
- 🐳 Docker support
- ☁️ Deployed on Render

## 🛠️ Tech Stack

- Python
- FastAPI
- LangGraph
- LangChain
- MCP (Model Context Protocol)
- HTML
- CSS
- JavaScript
- Docker
- Git & GitHub
- Render

## ⚙️ Installation

```bash
git clone https://github.com/vidit-biswas/TravelMatrix-AI---A-multi-agent-travel-planner.git

cd TravelMatrix-AI---A-multi-agent-travel-planner

python -m venv .venv

source .venv/bin/activate   # Linux/Mac
# or
.venv\Scripts\activate      # Windows

pip install -r requirements.txt

python app.py
```

## 🐳 Run with Docker

```bash
docker build -t travelmatrix .

docker run -p 10000:10000 travelmatrix
```
